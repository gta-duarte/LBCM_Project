# LBCM_Project
A repository for my project in cell and molecular biology, "Integrative and Interpretable Modeling of Copy-Number Variation (CNV) as Determinants of Cancer Gene Essentiality"

## Code Availability
Every analysis pipeline was implemented in R version 4.5.0 (2025-04-11), and the source code is available at https://github.com/gta_duarte/LBCM_Project under a GNU General Public License V3.

## Repository Structure
├── R/           # Analysis scripts, functions, and pipelines
├── data/        # Raw and processed datasets
├── output/      # Figures, tables, and computational results
├── LICENSE      # GPLv3 license
└── README.md    # This file

## Requirements
- R ≥ 4.5.0
- Package dependencies will be provided via `renv.lock` or `DESCRIPTION` upon code release.
